Panduan Ekstraksi AI & Kepatuhan UU PDP

Disdukcapil Kabupaten Madiun · Formulir F-2.01 A

1. Mengapa AI (LLM) Tepat untuk Data Mentah Copas?

Teks hasil copy-paste dari SIAK Terpusat (Ctrl+A), SIMRS rumah sakit, Puskesmas, atau chat WhatsApp memiliki format yang tidak seragam. AI mampu memahami konteks semantik seperti penulisan "Tn."/"Ny.", satuan gram ke kilogram, serta memisahkan tabel anggota keluarga secara akurat.

2. Pilihan Mesin Ekstraksi

  • Local AI via Ollama (Qwen 2.5 7B / Llama 3.1 8B): 100% komputasi berjalan lokal tanpa 1 byte pun data NIK/KK keluar ke internet (UU No. 27 Tahun 2022).
  • Smart Regex Parser (Offline): Deteksi instan tanpa LLM atau API Key untuk pola NIK 16 digit, No. KK, tanggal, jam, berat, dan tabel SIAK.
  • Google Gemini 2.5 Flash / OpenAI GPT-4o-mini: Opsi cloud API dengan Structured JSON Outputs berlatensi rendah.
